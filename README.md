# Nency — Personal Developer Portfolio

A responsive personal portfolio made with semantic HTML5, CSS Flexbox, CSS Grid, and a small amount of JavaScript.

## Files

- `index.html` — page structure and content
- `style.css` — styling, layout, and responsive media queries
- `script.js` — mobile navigation, current year, and GitHub placeholder warning

## Run locally

1. Download or extract these files into one folder.
2. Open `index.html` in a web browser.
3. For a smoother developer workflow, open the folder in Visual Studio Code and use the Live Server extension (optional).

No package installation or build command is required.

## Personalise before publishing

1. In `index.html`, replace `https://github.com/REPLACE-WITH-YOUR-USERNAME` with your real GitHub profile URL.
2. Review the bio and skill descriptions; edit them so they accurately describe you.
3. Add links to projects only after you have actually completed them.
4. Do not publish private phone numbers, home addresses, or other personal details.

## Publish with GitHub Pages

1. Sign in to GitHub and create a new **public** repository named `nency-portfolio` (or another name you prefer).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository's root.
3. Open the repository's **Settings → Pages**.
4. Under the build/deployment source, select **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. Wait for GitHub Pages to publish the site. The live URL will usually look like `https://YOUR-USERNAME.github.io/nency-portfolio/`.
7. Open the published URL on both a phone and a computer to test it. The URL can take a few minutes to become available.
